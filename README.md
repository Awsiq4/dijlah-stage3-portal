# بوابة طلبة المرحلة الثالثة — حزمة نقل وإعادة بناء

> **تنبيه مهم:** هذا المشروع **إعادة بناء جديدة من المواصفات المحفوظة**؛ ليس نسخة مستخرجة من مستودع الموقع الأصلي، ولا يحوي قاعدة بيانات Cloudflare D1 أو ملفات R2 الأصلية.

## الفكرة
بوابة طلابية مستقلة لطلبة **المرحلة الثالثة** — قسم **هندسة الليزر والإلكترونيات البصرية**، كلية الهندسة، **جامعة دجلة**، العام **2026–2027**. الاتجاه RTL، والعربية أساساً، والتوقيت Asia/Baghdad.

## تشغيل المشروع

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. للتحقق من ملفات TypeScript: `npm run typecheck`، ولإنشاء build: `npm run build`.

هذا مشروع Next.js + TypeScript + CSS عادي مع `lucide-react` لأيقونات الواجهة. لا يحتاج API keys لتشغيل **النموذج التجريبي**.

## ما الذي يعمل في الحزمة الجديدة؟
- واجهة رئيسية وجميع الصفحات: المواد، التفاصيل، المحاضرات، الجدول، الامتحانات، التبليغات، الواجبات، المزيد، التليجرام، واجهة المساعد الذكي.
- شريط تنقل سفلي: **الرئيسية، المواد، الجدول، التبليغات، المزيد**. الامتحانات في المزيد.
- الوضع المظلم/الفاتح محفوظ في متصفح المستخدم.
- اختيار الشعبة A/B/C/F محفوظ في المتصفح.
- **التبليغات** مقسمة إلى عامة، الشعبة، التدريسيين؛ الأولوية والتثبيت.
- لوحة إدارة **تجريبية محلية فقط** لتعديل أسماء التدريسيين، وتسجيل جدول ومحاضرات وامتحانات وواجبات وتبليغات وروابط قنوات؛ تصدير واستيراد JSON.
- اسم صاحب البرمجة **Aws Faris** في التذييل، من دون إضافة رابط موقع الجامعة للتذييل.

## ما الذي لا يعمل — ولا يجوز اعتباره مكتملاً؟
- **لا توجد قاعدة بيانات فعلية أو حسابات دخول أو API CRUD مع حماية**. جميع الإضافات في `/admin` تحفظ في `localStorage` لهذا المتصفح فقط؛ غير ملائمة للإنتاج.
- ملفات PDF الحقيقية، نسخ الملفات، الأرشفة والتخزين R2 غير مضمّنة.
- تكامل بوت التليجرام/إرسال الإشعارات **غير موجود**، فقط واجهة القنوات.
- خدمة RAG/OpenAI والإجابة على المحاضرات **غير موجودة**؛ صفحة المساعد واجهة غير مفعّلة عمداً.
- لم نستخرج 36 حصة من النسخة الأصلية، ولا مواعيد الأحد الثلاثة؛ لذلك الجدول فارغ بدلاً من إنشاء مواعيد خاطئة.
- استعدنا أسماء التدريسيين السبعة من **الجدول الأسبوعي المؤرخ 17-10-2026**؛ أدخلناها في المواد وملف CSV. يلزم مطابقتها مع آخر صورة للمدرسين والتغييرات الأحدث.
- **صور شعار الجامعة الأصلية** `IMG_3121.jpeg` و`IMG_3122.jpeg` غير مرفقة في هذه الحزمة؛ لا يوجد شعار جامعة متخيل.

## ملفات مهمّة

- `docs/HANDOFF_TO_OTHER_AI.md`: النص المرجعي للحساب الثاني؛ **اقرأه أولاً**.
- `docs/IMPLEMENTATION_STATUS.md`: التحقق من الحالة والنواقص والأولويات.
- `database/cloudflare-d1-schema.sql`: مخطط مقترح لقاعدة SQLite Cloudflare D1، **لم يُطبّق بعد**.
- `data/schedule-template.csv`: نموذج إدخال المواعيد الأصلية.
- `data/teachers-template.csv`: أسماء التدريسيين السبعة مستخرجة من الجدول المؤرخ 17 أكتوبر.
- `references/schedule-2026-10-17-extracted.txt`: النص المستخرج من PDF الجدول الأصلي (قد تفقد القراءة النصية هندسة الجدول؛ يلزم تدقيق بصري).
- `src/lib/seed.ts`: المواد السبع وبيانات البداية.
- `src/lib/storage.tsx`: الحالة المحلية للتجربة، **لا تستخدمه بوصفه تخزين إنتاجي**.

راجع `docs/HANDOFF_TO_OTHER_AI.md` للاستكمال.
